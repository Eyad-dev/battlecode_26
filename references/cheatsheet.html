Resources

Ti Titanium
Primary building resource. Each team starts with 1000 Ti. Harvested from titanium ore deposits.
Raw Ax Raw Axionite
Mined from axionite ore deposits. Fed to turrets/core it decays into titanium. Must be refined for advanced use.
Ref. Ax Refined Axionite
Produced by axionite foundries (1× Ti stack + 1× raw Ax stack → 1× refined Ax stack). Used for powerful units and turret ammo.

Builder Bot only mobile unit

Action radius²2

Can walk on: conveyors (any direction/team), roads (any team), allied core.

Actions (per action cooldown): Build any building or turret within radius • Heal all friendly entities on a tile by 10 HP

Destroy: Can destroy allied buildings within action radius — unlimited times per round, no cooldown cost.

Self-destruct: Deals 20 damage to the tile it stands on. Markers: 1 per round, free, separate from action cooldown.

Cooldown system

All units have action and move cooldowns (non-negative integers that decrease by 1 each round). Actions and movement require cooldown = 0. Moving costs +1 move cooldown. Building/healing costs +1 action cooldown.

Turrets (combat)

Ammo is fed via conveyors from any direction except the turret's facing direction. Turrets only accept ammo when completely empty. They can hold 1 stack of 1 resource type.
